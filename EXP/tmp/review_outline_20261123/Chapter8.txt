异步时序电路- Introduction
Asynchronous sequential circuits do not operate in pulse mode and do
not use flip-flops to represent state variables.
In an asynchronous sequential circuit, state changes are not triggered by
clock pulses.
State changes are dependent on whether each of the inputs to the circuit
has the logic level 0 or 1 at any given time.
For reliable operation, the inputs must change in a specific way.

Moreover, there must be sufficient time between the changes in input
signals to allow the circuit to reach a stable state, which is achieved when all
internal signals stop changing.
A circuit that adheres to these constraints is said to operate in the
fundamental mode.
Asynchronous circuits are much more difficult to design than synchronous
circuits, although they can be synthesized using similar techniques.

A flow table defines the state changes and outputs that must be
generated.
An excitation table depicts the transitions in terms of the state variables.
The excitation table derives from the fact that a change from a stable
state is performed by “exciting” the next-state variables to start
changing towards a new state.

异步时序电路-Analysis
Analysis of asynchronous circuits or synchronous circuits is a procedure
to obtain the system functions from the given circuits.
It is the reverse process of circuit design:
First, next-state and output expressions are derived from the circuit.
Then, the excitation table corresponding to the next-state and output
expressions is derived.
Then, a flow table is obtained.
At last, a corresponding state diagram is derived from the flow table.

To analyze the circuit, each feedback path is cut, and a delay element is inserted at the cut point.
The input signal to the delay element represents a corresponding next-state variable,Yi, while the
output signal is the present-state variable,yi.
A cut can be made anywhere in a particular loop formed by the feedback connection, as long as
there is only one cut per loop.
Thus, the number of cuts that should be made is the smallest number that results in there being no
feedback anywhere in the circuit.
This minimal number of cuts is referred to as thecut set.
Note that the analysis based on a cut made at one point in a given loop may not produce the same
flow table as an analysis on a cut made at another point in this loop. Both flow tables would reflect
the same functional behavior in terms of the applied inputs and generated outputs.

异步时序电路-Design
The design of asynchronous sequential circuits follows the same basic steps 
used to design synchronous circuits.
The basic steps are:
Devise a state diagram for an FSM that realizes the required basic behavior.
Derive the flow table and reduce the number of states if possible.
Perform the state assignment and derive the excitation table.
Obtain the next-state and output expressions.
Construct a circuit that implements these expressions.

Let A be the state that indicates that an even number of pulses has been received. The
output z will be 0 when the circuit is in stateA.
As long asw = 0, the circuit remains inA. Thus,A is stable whenw = 0.
When the next pulse arrives, the inputw = 1, and stateB is reached, makingz = 1.
State B remains stable as long asw = 1.
The next input change occurs whenw goes to 0. In response, the system changes to state
C, where z = 1, showing that a complete pulse has been observed.
It is stable under the inputw = 0. The arrival of the next pulse makesw = 1, and the
system changes to stateD, indicating that an even number of pulses has been observed.
The stateD is stable underw = 1, and it causes the output to bez = 0.
Finally, whenw returns to 0 at the end of the pulse, the FSM returns to stateA, which
indicates an even number of pulses andw equal to 0 at that moment.

Design of a simple arbiter to implement resource sharing.
Suppose that two devices are competing for the shared resource. Each device
communicates with the arbiter by means of two signals—Request and Grant.
When a device needs to use the shared resource, it raises its Request signal to
1. Then it waits until the arbiter responds with the Grant signal.

A device initiates the activity by raising a request,r = 1.
When the shared resource is available, the arbiter responds by issuing a grant,g = 1.
When the device receives the grant signal, it proceeds to use the shared resource.
When it completes its use of the resource, it drops its request by settingr = 0. When
the arbiter sees thatr = 0, it deactivates the grant signal, makingg = 0.
The arrows in the figure indicate the signal relationships: a change in one signal causes
a change in the other signal. The time elapsed between the changes in the signals
depends on the specific implementation of the circuit.
A key point is that there is no need for a synchronizing clock.
A state diagram for the simple arbiter can be obtained with two inputs, the request

The transitions between statesB and C involve changes in both state variablesy1 and y2.
If stateB is stable under input valuationr2r1 = 11, and the inputs change tor2r1 = 10, it
will go to stateC, and the state variables must change fromy2y1 = 01 to 10.
If y1 changes faster thany2, then the circuit will find itself momentarily in statey2y1 =
00, which leads to the desired final state because from stateA there is a specified
transition toC with r2r1 =10.
But ify2 changes faster thany1, the circuit will reach the statey2y1 = 11, which is not
defined in the flow table.
To make sure that the circuit will proceed to the required destinationC, a new statey2y1
= 11, labeledD, is included in the excitation table to specify the required transition.
A similar situation appears when the circuit is stable inC with r2r1 = 11, and it has to
change toB when r2 changes from 1 to 0.
