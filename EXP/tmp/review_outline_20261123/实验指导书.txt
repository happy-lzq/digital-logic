必做题 1 D 锁存器与 D 触发器 20% 
运行提供的 RTL 与 testbench，对比两种一位存储电路。无需补写代码；完成仿真截图与简要分析。 
时序电路能够保存状态，输出不仅取决于当前输入，还与此前保存的状态有关。锁存器和触发器都能保
存一位数据，区别在于更新时机。 
两个模块均为 clk、d 输入和 q 输出，均为 1 位，无复位。dlatch 在 clk=1 期间透明、clk=0 时保持；dff 仅
在 clk 上升沿采样 d，其余时间保持。 
 
图 1 相同输入下的锁存器与触发器 
提供的 RTL 
`timescale 1ns/1ps 
// D latch: transparent while clk is high, holds while clk is low. 
module dlatch(input wire clk, input wire d, output reg q); 
    always @(*) begin 
        if (clk) q <= d; 
    end 
endmodule 
 
// D flip-flop: samples d only on a rising clock edge. 
module dff(input wire clk, input wire d, output reg q); 
    always @(posedge clk) begin 
        q <= d; 
    end 
endmodule 
注意事项 电平敏感与边沿触发 
锁存器使用 always @(*)，保持分支有意不赋值；触发器使用 always @(posedge clk)。均用 <=。首次采样前输
出可能为 X。

以 tb_storage 为顶层运行 Run All，预期 STORAGE PASS、checks=13、failed_checks=0。完整测试源码见文
末，保存为 sim/tb_storage.v。

必做题 2 两级寄存器与非阻塞赋值 40% 
模块名：pipeline2。两个串联的 D 触发器，只在时钟上升沿更新，沿间保持。 
设计规则：在 always @(posedge clk) 中，优先判断复位；rst=1 时将两个输出清零，否则让 q1 采样 
d，q2 采样更新前的 q1。赋值使用 <=。 
端口名 方向与位宽 含义 
clk 输入，1 位 上升沿更新 
rst 输入，1 位 高电平同步复位 
d 输入，1 位 第一级输入 
q1、q2 输出，各 1 位，reg 第一级、第二级保存的值 
 
图 2 两级寄存器的数据传递框图 
 
为什么使用非阻塞赋值 
q1 <= d; 
q2 <= q1; 
非阻塞赋值先计算右侧，再在当前仿真时刻的后续阶段更新左侧。因此第二句使用旧 q1，不会直接得到
本拍的 d。 
注意事项 赋值方式 
例如上升沿前 d=1、q1=0、q2=0，更新后为 q1=1、q2=0。若按该顺序改成 q1 = d; q2 = q1;，第二句会使用已修改的 
q1，不符合两级传递要求。

第一题 testbench 源码 
文件名 tb_storage.v。复制完整代码即可使用。 
`timescale 1ns/1ps 
module tb_storage; 
    reg clk = 0, d = 0; 
    wire q_latch, q_dff; 
    integer checks = 0, errors = 0; 
    dlatch u_latch(.clk(clk), .d(d), .q(q_latch)); 
    dff u_dff(.clk(clk), .d(d), .q(q_dff)); 
 
    task check; 
        input expected_latch, expected_dff; 
        begin 
            #1; // Wait for nonblocking assignments to complete. 
            checks = checks + 1; 
            if ({q_latch, q_dff} !== {expected_latch, expected_dff}) begin 
                errors = errors + 1; 
                $display("FAIL t=%0t clk=%b d=%b latch=%b dff=%b", 
                         $time, clk, d, q_latch, q_dff); 
                $display("Expected: latch=%b dff=%b", 
                         expected_latch, expected_dff); 
            end 
            #4; 
        end 
    endtask 
 
    initial begin 
        // Change d before clock edges, avoiding stimulus races. 
        #5; clk = 1; check(0, 0); // 5 ns: first rising edge. 
        d = 1; check(1, 0);      // 10 ns: high level, latch follows. 
        d = 0; check(0, 0);      // 15 ns: high level, latch follows. 
        d = 1; check(1, 0);      // 20 ns: dff still holds. 
        clk = 0; check(1, 0);    // 25 ns: falling edge, both hold. 
        d = 0; check(1, 0);      // 30 ns: low level, both hold. 
        d = 1; check(1, 0);      // 35 ns: prepare before rising edge. 
        clk = 1; check(1, 1);    // 40 ns: dff samples d=1. 
        d = 0; check(0, 1);      // 45 ns: outputs differ again. 
        clk = 0; check(0, 1);    // 50 ns: both hold. 
        d = 1; check(0, 1);      // 55 ns: low level, both hold. 
        d = 0; check(0, 1);      // 60 ns: prepare d=0. 
        clk = 1; check(0, 0);    // 65 ns: dff samples d=0. 
        $display("=========="); 
        if (errors == 0) $display("STORAGE PASS"); 
        else $display("STORAGE FAIL"); 
        $display("checks=%0d; failed_checks=%0d", checks, errors); 
        $display("=========="); 
        $finish; 
    end 
    initial begin 
        #1000; 
        $display("==========\nSTORAGE FAIL\nReason: TIMEOUT\n=========="); 
        $finish; 
    end 
endmodule
