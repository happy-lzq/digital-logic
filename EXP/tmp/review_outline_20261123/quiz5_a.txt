Smiling Snail 微笑蜗牛  0111 序列检测器 
每个时钟周期读入一位，当最近连续四位为 0111 时输出微笑信号，随后继续检测。采用四状态 Mealy 
型状态机，由两只 D 触发器及组合逻辑实现。 
一  状态定义与状态转移图 
令输入为 x，微笑输出为 y。状态记录已读序列的最长后缀，且该后缀同时是目标序列 0111 的前缀。
复位时处于 S0，y = 0。 
状态 含义 编码 Q1Q0 
S0 尚无有效前缀 00 
S1 已匹配 0 01 
S2 已匹配 01 11 
S3 已匹配 011 10 
 
图中弧标记为 x/y。S3 遇到 1 时检测成功，输出 1 并回到 S0；任一状态遇到 0，都保留这个新起点
并转到 S1。 
二  原始状态表 
现态 x = 0 时 次态 / y x = 1 时 次态 / y 
S0 S1 / 0 S0 / 0 
S1 S1 / 0 S2 / 0 
S2 S1 / 0 S3 / 0 
S3 S1 / 0 S0 / 1 
四个状态不能合并：S3 可由后续输入 1 区分；S2 与 S0、S1 可由后续输入 11 区分；S1 与 S0 可由
后续输入 111 区分。因此最少需要四个状态，即两位状态存储。

采用上页编码，Q1⁺、Q0⁺ 表示下一状态。D 触发器满足 Q⁺ = D，因此下一状态表也就是 D 输入真值表。

化简时，变量排列统一为 Q1、Q0、x，最小项编号按二进制值计算。字母上方的横线表示取反，· 表示
与，+ 表示或。 
D1 = Σm(3, 7) = x·Q0 
D0 = Σm(0, 2, 3, 4, 6) = 𝑥 + 𝑄1·Q0 
y = Σm(5) = x·Q1·𝑄0 
推导：当 x = 0 时，次态恒为 01；当 x = 1 时，D1 = Q0，D0 = 𝑄1·Q0。故 D0 = 𝑥 + x·𝑄1·Q0 = 
𝑥 + 𝑄1·Q0。只有现态 10 且 x = 1 时 y = 1。

四  门级电路实现与接线说明 
 
图中采用常见的门电路轮廓符号：左平右圆的门为与门，输入侧及输出侧均为弧形的门为或门，输出带
小圆圈的三角形为非门。D 触发器左侧三角形为上升沿时钟端，CLR 为高电平有效异步清零端。 
所有同名网络在电气上相连：x 是唯一串行数据输入；Q1、Q0 分别来自上、下两只 D 触发器的 Q 输出，
并接到图中全部同名输入处。D1、D0 分别接相应触发器的 D 端，y 是唯一微笑输出。CLK 和 CLR 分别
为两只触发器的公共时钟和复位输入。 
按方程接线：D1 使用一个二输入与门；D0 使用 x 和 Q1 的反相器、一个二输入与门及一个二输入或门；
y 使用 Q0 的反相器和一个三输入与门。若触发器有反相输出端，可直接使用相应反相信号。 
两只 D 触发器共用上升沿时钟，复位均清零到 00。每周期输入在有效时钟沿前满足建立时间，并在时
钟沿后满足保持时间；时钟沿将组合逻辑产生的 D1D0 装入状态寄存器。

五  输入实例与时序核对 
以下“现态”是采样该位前的状态，“y”是该输入与现态决定的 Mealy 输出，“次态”在本次有效时
钟沿更新。输入序列 0011101111 应仅在第 5、9 位检测成功。 
位序 输入 x 现态 输出 y 次态 
1 0 S0 0 S1 
2 0 S1 0 S1 
3 1 S1 0 S2 
4 1 S2 0 S3 
5 1 S3 1 S0 
6 0 S0 0 S1 
7 1 S1 0 S2 
8 1 S2 0 S3 
9 1 S3 1 S0 
10 1 S0 0 S0 
连续 0 会保持在 S1，避免漏掉新的起点；01111 只在第 4 位微笑，第 5 位不微笑；01110111 可在第 
4、8 位各检测一次。序列 0111 没有非空真前缀与真后缀相同，因此一次完整匹配后回到 S0 即可。 
六  Mealy 型输出时序说明 
Mealy 输出由现态和当前输入直接产生：在 S3 期间输入 x = 1 即置 y = 1，更新到 S0 后 y 回到 0。
因此 y 可在采样第四位的时钟沿之前有效，实际脉宽取决于输入时序；它不自动保证为完整一个时钟周
期。若将 y 用作同步使能，应在有效时钟沿采样，并保证输入时序稳定。
