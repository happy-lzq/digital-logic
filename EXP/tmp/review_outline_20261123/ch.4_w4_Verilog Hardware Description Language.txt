Value Set 数值种类
◆ The Verilog HDL value set consists of four basic values:
0 - represents a logic 0, or a false condition
1 - represents a logic 1, or a true condition
x or X - represents an unknown logic value 未知态
z or Z - represents a high-impedance state 高阻态

◆ Vectors
➢ Both net and reg can be declared as vectors 
e.g. reg a; // a scalar reg
reg [3:0] v; // a 4-bit vector reg made up of (from most to

➢ A net or a variable (either scalar or vector) can be declared as

of type reg is also called a memory

Data Types
◆ Memory
➢ Can be used to model read-only memories (ROMs), random 
access memories (RAMs), and reg files 
e.g. reg [7:0] mema [0:255]; // declares a memory mema of 256 8-bit registers
mema = 0; // illegal syntax- attempt to write to entire array
mema[1] = 0; // assigns 0 to the second element of mema
mem[127] = 8'b0 ;         // assign 8’b0 to the 128th element of mema
reg arrayb [7:0] [0:255]; // declare a two-dimensional array of 1-bit registers 
arrayb[1] = 0; // illegal syntax 
arrayb[1][12:31] = 0; // illegal syntax
arrayb[1][0] = 0; // assigns 0 to the bit referenced by indices [1][0]
